## 🚀 How to Run Locally

You can launch the site immediately with Node.js:

```bash
# Start the local live server
npm start
# or:
node server.js
```

Then open your browser at:
👉 **`http://localhost:5173`** (or port displayed in terminal)

Alternatively, double click [index.html](file:///i:/SRB%20STUDIOS/index.html) to open directly in any browser.


2. In Repository Settings -> Pages, select `main` branch root `/` and save.
